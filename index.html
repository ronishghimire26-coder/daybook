Set up once
1
Make a Daybook calendar
Calendar app → Calendars → Add Calendar → “Daybook”.
2
Export and import
Tap Export above → Save to Files. In Files, open the file (tap the zip first if you got one), then tap the .ics → Add All → Daybook.
3
Allow alerts
Settings → Notifications → Calendar → Allow, and turn on Time Sensitive.
4
Add the widget
Hold the Home Screen → Edit → Add Widget → Calendar → Up Next.
5
After edits
Delete the Daybook calendar, make it again, and repeat step 2.
